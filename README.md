## 💣 지뢰찾기 (Minesweeper)

<p align="center">
  <a href="https://crowtit517.github.io/Agent_Ai/games/minesweeper/index.html">
    <img src="https://img.shields.io/badge/▶_바로_플레이하기-e94560?style=for-the-badge" alt="바로 플레이하기">
  </a>
</p>

어릴 적 윈도우에 깔려있던 그 지뢰찾기를, 어두운 네이비 톤으로 다시 그려봤습니다.
설치도 로그인도 필요 없이, 위 버튼 하나만 누르면 바로 게임이 시작돼요.

> 🔗 **바로가기:** https://crowtit517.github.io/Agent_Ai/games/minesweeper/index.html

### 소개

윈도우 클래식 지뢰찾기를 웹으로 옮기면서, 원작에 없던 디테일을 몇 가지 더했습니다.
숫자 색상을 8개 전부 다르게 칠하고, 지뢰를 밟았을 때 살짝 튀어오르는 애니메이션을 넣어서
"눌렀다"는 느낌이 확실히 들도록 만든 게 포인트예요.

### ✨ 특징

| 기능 | 설명 |
|---|---|
| 🕹️ 난이도 3단계 | 쉬움(9×9·10개) · 보통(16×16·40개) · 어려움(30×16·99개) |
| ⏱️ 실시간 타이머 | 첫 클릭 시작 시점부터 999초까지 카운트 |
| 🚩 깃발 표시 | 우클릭으로 지뢰 의심 칸에 깃발 꽂기 |
| 😊 상태 표정 | 진행 중 😊 → 실패 😵 → 승리 😎 로 즉시 반응 |
| 🎨 다크 UI | 네이비 배경 + 카드형 보드, 숫자별 8색 구분 |

### ▶️ 플레이 방법

1. 위 **"바로 플레이하기"** 버튼 클릭
2. 좌클릭으로 칸 열기, 우클릭으로 깃발 표시
3. 원하는 난이도는 하단 버튼으로 언제든 전환

### 🛠 기술 스택

- 순수 **HTML / CSS / JavaScript** (프레임워크·빌드 과정 없음)
- 파일 하나로 동작 → 다운로드 후 더블클릭만 해도 로컬에서 바로 실행 가능

## 🌙 달빛달력 (Moonlight Calendar)

<p align="center">
  <a href="https://crowtit517.github.io/moonlight_calendar/">
    <img src="https://img.shields.io/badge/▶_바로_사용해보기-6d5fd3?style=for-the-badge" alt="바로 사용해보기">
  </a>
</p>

하루에서 며칠까지, 원하는 색으로 일정을 담아두는 다크 테마 캘린더입니다.
일정 관리뿐 아니라 그날그날의 지출을 기록하는 가계부까지 한 화면에 담았어요.

> 🔗 **바로가기:** https://crowtit517.github.io/moonlight_calendar/

### 소개

남색과 보랏빛이 감도는 밤하늘 톤 위에, 하루짜리 일정부터 여러 날에 걸친 일정까지
막대 형태로 한눈에 볼 수 있도록 그렸습니다. 날짜를 누르면 그날의 일정과 지출을
함께 확인할 수 있는 패널이 옆에 붙어 있어요.

### ✨ 특징

| 기능 | 설명 |
|---|---|
| 📅 기간 일정 | 하루짜리부터 여러 날짜에 걸친 일정까지, 달력 위에 막대로 표시 |
| ⏰ 시간 지정 | 오전/오후 스크롤 선택 또는 직접 입력 모두 지원 |
| ✅ 할 일 모드 | 일정을 할 일로 등록하고 체크박스로 완료 표시 |
| 🎨 색상 커스터마이즈 | 5가지 프리셋 색상 + 원하는 색을 직접 고르는 컬러 피커 |
| 🪙 가계부 | 날짜별 지출 기록, 월별·연간 지출 그래프까지 자동 집계 |

### 🛠 기술 스택

- 순수 **HTML / CSS / JavaScript** (프레임워크·빌드 과정 없음)
- 별도 저장소 [moonlight_calendar](https://github.com/Crowtit517/moonlight_calendar)에서 관리됩니다.
